# Green Shovel Project website

Static site for the Green Shovel Project, a Cal Poly student-run nonprofit in San Luis Obispo. Deployed on Vercel; every push to `main` redeploys.

- Pages: `index.html`, `about-us/`, `our-events/`, `latest-news/`, `support-our-mission/`
- Styles: `_astro/` (`updates.css` holds the newer sections: next event, impact stats, partners)
- Images: `images/` (partner logos in `images/partners/`)
